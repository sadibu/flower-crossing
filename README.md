# Zebrastreifen in Blüte

Ein interaktiver Zebrastreifen von oben: Passanten mit Blumen statt Köpfen.

**Live:** https://sadibu.github.io/flower-crossing/

- Blüte antippen: Sie wird gegen eine andere getauscht.
- Auf den Asphalt tippen: Eine neue Person geht los.
- Ampel (oder Leertaste): Rot bleiben alle stehen, Grün gehen sie weiter.
- Regen, Tempo und „Alle neu erblühen“ in der Leiste unten.

## Blütenjagd

Ein Spiel mit Zeitlimit: 1, 3 oder 5 Minuten. Jede Blüte derselben Art bringt einen Punkt mehr als die vorige (1, 2, 3 …). Triffst du eine andere Art, beginnt die Serie mit dieser Art neu. Ein Tipp auf den Asphalt beendet die Serie. Deine Bestwerte speichert dein Browser.

Eine einzelne HTML-Datei ohne Build-Schritt. Alles wird mit Canvas gezeichnet.
